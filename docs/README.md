# Arbaz Khan — Discord Banner Designer

A modern, responsive single-page portfolio website for Arbaz Khan, a Discord banner designer based in Pakistan, specializing in gaming communities.

## Features

- **Dark gaming theme** with neon blue, purple, and pink accents
- **Hero section** with animated Discord banner preview carousel
- **About section** highlighting Pakistan background and experience
- **Services section** covering banner design, icon design, and full branding
- **Portfolio gallery** with 5 sample banners featuring CSS/SVG-generated designs
- **Contact form** with Discord integration and interactive notifications
- **Fully responsive** design for all device sizes
- **Smooth animations** — glowing orbs, floating particles, scroll-triggered reveals, custom cursor
- **GitHub Pages** deployment with custom domain support

## Design Highlights

- **Font**: Orbitron (headings) + Exo 2 (body text) — cyberpunk/gaming aesthetic
- **Color palette**: #00d4ff (neon blue), #b900ff (neon purple), #ff00e6 (neon pink)
- **Animations**: CSS keyframes for banners, scan lines, floating orbs, badge pulse
- **Custom cursor** with hover trail effect
- **Glass-morphism** cards with backdrop blur
- **Gradient text** using CSS background-clip

## Tech Stack

- **Vanilla HTML5** — semantic structure
- **CSS3** — Grid, Flexbox, custom properties, backdrop-filter, animations
- **JavaScript (ES6+)** — Intersection Observer, FormData API, CSS custom properties
- **SVG/CSS** — Generated banner images (no external image dependencies)
- **Font Awesome 6.5** — Icons
- **Google Fonts** — Orbitron, Rajdhani, Exo 2

## Deployment

Deployed to GitHub Pages at: https://arbazkhan.dev
